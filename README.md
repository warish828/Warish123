# Warish Code Lab

A mobile-friendly browser coding playground for HTML, CSS and JavaScript.

## Features
- HTML/CSS/JavaScript editor
- Live preview
- Local autosave with localStorage
- Copy code
- Download a standalone HTML project
- Starter reset and new project
- Dark/light theme
- Challenges, tutorials and quick reference
- Responsive mobile layout
- Sandboxed preview iframe

## Deploy
This is a static website. Upload the contents of this folder to GitHub Pages, Netlify, Cloudflare Pages, or any static hosting service.

No backend or API key is required for the core lab.

## Files
- index.html
- style.css
- script.js
